# 🎵 局域网点歌机使用说明

局域网点歌机让多人通过浏览器搜索歌曲、加入队列、顶歌和投票跳过。歌曲由运行程序的电脑通过 mpv 播放到音响；手机和其他电脑用于点歌与管理，不会各自播放音频。

支持网易云音乐和 QQ 音乐。管理员可以控制播放、调整音量和输出设备、管理队列、切换背景歌单，并设置定时播放任务。

本文按 **v1.0.20** 编写：支持双平台歌单管理、QQ 私人雷达、歌曲响度均衡、管理端控制设置，以及带独立进度窗口的自动更新。推荐普通用户使用 Windows 安装包；源码运行和构建步骤单独列在下文。

## Windows 桌面版

桌面版面向 Windows 10/11 x64，安装包名为 `Jukebox-Setup-<版本>-x64.exe`。安装包内置运行环境和 mpv，使用者无需安装 Node.js 或执行启动脚本。

**[下载 Windows x64 安装程序 v1.0.20](https://github.com/sangui0312/jukebox-/releases/download/v1.0.20/Jukebox-Setup-1.0.20-x64.exe)** · **[查看最新版本说明与校验文件](https://github.com/sangui0312/jukebox-/releases/latest)**

源码可通过本仓库的 **Code → Download ZIP** 下载，或使用下文的 Git 命令获取。安装程序位于 Release 的 **Assets**，不需要下载整个源码仓库。

1. 下载并运行安装程序。选择磁盘或父文件夹后，会自动添加 `JukeboxDesktop` 文件夹；安装完成打开程序。
2. 首次启动设置至少 8 个字符的管理口令；之后在管理台用此口令登录。
3. 等待状态显示“服务运行中”，点击“打开点歌台”或“打开管理台”。
4. 在管理台的“平台账号与渠道”登录自己的音乐账号，验证后自动保存；浏览器版可手动填写 Cookie。点歌试听。
5. 将主窗口显示的“互联网访问地址”分享给同一局域网的设备。这里只显示一个局域网地址，仍需连接同一网络。

### 软件窗口与退出

首页与设置、点歌台、管理台在同一个窗口顶部切换，采用统一的页面风格。标题栏支持拖动、最小化和最大化；执行在线更新时会额外弹出独立更新窗口。

关闭窗口会收起到托盘并继续运行。需要完全退出时，点击顶部右侧的 **退出软件**，或在系统托盘菜单中选择 **退出**，程序会停止自己的服务与播放器。**重启全部服务**会保存状态后重启；管理台的 **关闭服务**仅停止主服务，可以从首页点击 **启动主服务**恢复。

### 端口与手机访问

首页的 **端口设置**默认收起，点击展开后可以修改点歌服务端口（1024–65535，默认 8080）。保存后重启服务，手机点歌地址同步更新；下次启动继续使用这个端口。主端口被占用时，请在此处选择其他端口，程序不会结束占用它的应用。更改端口后，也要更新防火墙的放行规则。

QQ 与网易云内部接口仅监听本机，默认使用 3400 和 4000；被占用时自动选择空闲端口，内部连接同步更新。手机只需访问首页显示的点歌地址，不需要访问这两个内部接口。

### 修改管理口令

在首页与设置中展开 **修改管理口令**，输入原口令、新口令和确认口令。新口令为 8–128 个字符；修改成功后，下次进入管理台使用新口令。运行中修改会重启主服务；主服务已停止时保持停止，重新启动后新口令生效。音乐平台登录信息和其他配置会保留。

### 程序内登录音乐平台（桌面版 v1.0.2 起）

进入管理台，在 **平台账号与渠道** 点击 **登录网易云** 或 **登录QQ音乐**。在同一窗口的官方页面完成登录，程序验证成功后自动保存账号信息并返回管理台，无需打开 F12 或手动复制 Cookie。首页不设登录入口。

若登录后没有自动完成，可点击顶部 **重新检查登录**；点击 **管理台** 返回并取消本次获取。验证失败不会覆盖已有账号信息。程序使用各平台独立登录会话，不读取默认浏览器的账号信息。浏览器访问管理台时仍保留手动填写 Cookie 的方式。

QQ 账号在音乐接口启动时尝试续期一次，运行期间每 4 小时再尝试。只有腾讯返回新密钥后才保存；刷新失败保留原 Cookie，不代表当前登录已失效。微信登录不使用该续期接口，平台要求重新登录时仍需手动登录。

播放、自然结束、切歌以及暂停/继续均有约 1 秒淡入淡出。暂停后保留播放进度；继续时接着播放。双平台默认开启自动响度均衡，缩小不同歌曲的响度差异并限制音频峰值；音量滑块继续控制整体音量。在线音源采用实时均衡，无法保证每首歌的听感完全一致；如需关闭，可在本地配置中设置 `loudnessNormalization: false`。

### 更新与用户数据

首页的 **软件更新**会在启动时从本仓库 GitHub Releases 检查新版，也可点击 **检查更新**。发现新版后显示版本说明，点击 **立即更新** 才开始下载。

v1.0.15 及之后的版本会自动完成更新：

1. 弹出独立更新窗口，显示下载百分比；下载期间主程序继续运行。
2. 安装包下载并校验成功后，保存队列和用户数据，停止服务并自动退出主程序。
3. 独立窗口继续显示安装状态；安装阶段显示等待动画，不提供准确百分比。
4. 安装完成后自动启动新版，更新窗口随后关闭。默认仍保持暂停，点击“开始播放”继续听歌。

无需手动退出。下载或校验失败时不会安装更新，可关闭失败提示窗口并重新检查，或打开 **GitHub 版本页面**手动下载。安装或启动超过约 5 分钟时，窗口会提示可以关闭并手动打开点歌机。

v1.0.14 及更早版本仍按旧界面提示自行退出一次，升级后才使用新流程。手动安装新版时，也应先点击 **退出软件**或托盘 **退出**，再选择原安装位置覆盖安装；**关闭服务**和右上角 × 都不等于退出整个应用。

桌面用户数据保存在 `%APPDATA%/JukeboxDesktop`，可通过“用户数据”按钮打开。其中 `server/` 保存配置、队列和定时任务，`qq/` 保存 QQ Cookie。桌面版首次使用独立数据目录，不自动导入源码版的账号与队列；覆盖安装和默认卸载保留用户数据。

安装包未做代码签名，Windows 可能显示未知发布者提示。请从本仓库 Release 下载，并使用同名 `.sha256` 文件核对安装程序；PowerShell 中可运行 `Get-FileHash -Algorithm SHA256 -LiteralPath './Jukebox-Setup-1.0.20-x64.exe'`。

安装包包含第三方运行组件，其许可文件保存在安装目录的 `resources/licenses`，Electron 的许可文件位于安装目录。mpv、FFmpeg 版本、上游源码和构建来源记录在 [desktop/mpv-source.json](desktop/mpv-source.json)。

### 从源码构建桌面安装包

构建需要 Windows x64、Node.js 22.12 或更高版本、PowerShell 7 和 Git。在项目根目录运行：

```powershell
npm --prefix ./web ci
npm --prefix ./web run build
npm --prefix ./desktop ci --ignore-scripts
node ./desktop/node_modules/electron/install.js
pwsh -NoProfile -File ./desktop/scripts/fetch-mpv.ps1
npm --prefix ./desktop run prepare-runtime
npm --prefix ./desktop test
npm --prefix ./desktop run build -- --config.electronDist=node_modules/electron/dist --publish never
```

播放器下载脚本验证固定版本和 SHA-256；准备脚本在独立 staging 安装后台生产依赖，排除本机 Cookie、配置、状态和日志。开发运行使用 `npm --prefix ./desktop start`，安装产物位于 `desktop/release/`。

发布在线更新时，创建高于已安装版本的正式 GitHub Release，并同时上传同次构建的 `Jukebox-Setup-<版本>-x64.exe`、对应 `.exe.blockmap` 和 `latest.yml`。`latest.yml` 包含安装包的版本、下载地址和 SHA-512 校验信息，不要手工修改；只有安装包而没有此文件的旧 Release 无法用于在线更新。更新客户端使用公开仓库，不需要填写 GitHub Token。

如果构建下载报证书链错误，可在当前 PowerShell 会话设置 `$env:NODE_OPTIONS = '--use-system-ca'` 后重试，以使用系统受信任证书；不要关闭证书验证。具体第三方组件版本和来源在 `desktop/mpv-source.json` 及安装资源的许可目录中记录。

下面的“首次安装”步骤适用于保留的浏览器/源码运行方式。桌面安装包用户无需再次安装这些依赖。

## 安装前准备

准备一台连接音响、能访问音乐平台的电脑作为服务电脑。使用期间保持电脑开机、联网，并避免休眠。参与点歌的设备需要能访问服务电脑，通常应连接同一局域网。

需要安装：

- Node.js 22.12 或更高版本，安装时启用 PATH 选项；与桌面构建使用同一版本可避免依赖的运行环境要求不一致。
- [mpv 播放器](https://mpv.io/)，用于实际播放音频。
- PowerShell 7，用于执行本文的 Windows 安装命令。文本配置文件使用 UTF-8 编码。
- Git（可选）：使用 Git 下载项目时需要；也可在仓库页面选择 **Code → Download ZIP**，解压使用。

音乐平台账号按需配置。能搜索到歌曲不代表账号具有该歌曲的播放权限。

## 首次安装

### 1. 下载并进入项目目录

```powershell
git clone https://github.com/sangui0312/jukebox-.git jukebox
Set-Location -LiteralPath './jukebox'
```

如果已经下载或解压，直接进入包含 `server`、`web`、`QQMusicApi` 和 `start.bat` 的目录。下面所有安装命令均在这个项目根目录执行。

### 2. 安装依赖与构建网页

```powershell
npm --prefix ./server install
npm --prefix ./web install
npm --prefix ./netease-api install
npm --prefix ./QQMusicApi install --omit=dev
npm --prefix ./web run build
```

每条命令执行成功后再进行下一条。构建会生成 `web/dist`，主服务直接托管这些页面。

### 3. 创建本地配置

首次安装时复制模板：

```powershell
Copy-Item -LiteralPath './server/config.local.example.js' -Destination './server/config.local.js'
```

已有 `config.local.js` 的用户应保留原文件，避免覆盖账号和管理口令。

用文本编辑器打开 `server/config.local.js`，至少检查以下字段：

```javascript
adminKey: '请替换为自己的管理口令',
mpvPath: 'D:/tools/mpv/mpv.exe',
playlistId: 3778678,
autoStart: false,
```

- `adminKey`：管理员登录口令，必须自行设置；留空会禁用管理功能。
- `mpvPath`：填写真实的 mpv 程序位置。已加入 PATH 时可保留 `'mpv'`。Windows 路径建议使用 `/`。
- `playlistId`：默认网易云歌单 ID；未配置或设为 `0` 时使用热歌榜（3778678），已有自选歌单保留。
- `qqPlaylistId`：QQ 自选歌单 ID，默认 `0` 表示使用 QQ 热歌榜；通常在管理台搜索名称或粘贴链接添加即可，无需手填 ID。
- `loudnessNormalization`：默认 `true`，开启双平台响度均衡；设为 `false` 可关闭。
- `autoStart`：默认 `false`，启动后等待管理员点击“开始播放”。

配置格式为 JavaScript，字符串保留引号，字段之间保留逗号。使用 UTF-8 保存。修改本地配置后重启主服务生效。

## 启动与访问

### 启动程序

在项目根目录双击 `start-silent.vbs`，隐藏启动窗口并在后台运行。也可以在 PowerShell 中执行：

```powershell
./start.bat
```

启动脚本启动三个服务：

| 服务 | 默认端口 | 用途 |
| --- | --- | --- |
| 主服务 | 8080 | 点歌页面、管理页面与播放控制 |
| QQ 音乐 API | 3400 | QQ 音乐搜索与音源获取 |
| 网易云音乐 API | 4000 | 网易云音乐搜索与音源获取 |

脚本会检查默认端口是否被占用。显示启动提示后，仍需通过网页或日志确认服务正常。

### 服务电脑先自行访问

- 点歌台：<http://127.0.0.1:8080>
- 管理台：<http://127.0.0.1:8080/admin.html>

输入配置中的管理口令，点入一首歌，再点击“开始播放”，确认音响有声音。默认启动不会自动出声。

### 分享给其他设备

在服务电脑执行 `ipconfig`，找到当前网络的 IPv4 地址，将下面的 `<服务电脑IP>` 替换为该地址：

```text
点歌台：http://<服务电脑IP>:8080
管理台：http://<服务电脑IP>:8080/admin.html
```

其他设备上的 `127.0.0.1` 指向设备自己，必须使用服务电脑的地址。Windows 防火墙应允许主服务在所使用的局域网中通信；其他设备访问页面主要需要主服务的 8080 端口。

若修改默认端口，还需同步调整启动脚本中的端口检查，以及相应 API 地址。

## 普通用户点歌

### 设置昵称

点击页面顶部的昵称按钮，在页面内输入新昵称并点击“保存”（最多 12 个字符）；“取消”保留原昵称。昵称会同步到该用户尚未播放的队列歌曲。

程序按浏览器标识与访问 IP 识别用户，相同 IP 的多个入口会合并为同一身份，共享点歌限额、删歌权限和投票次数。多人通过同一个代理访问时，可能被识别为同一个用户。

### 搜索与加入队列

1. 在搜索区选择“网易云”或“QQ音乐”。
2. 输入歌名或歌手名并搜索。
3. 点击结果中的点歌按钮；也可以从榜单中选择歌曲。
4. 在插播队列中查看排序、点歌人和预计播完时间。

普通点歌排在插播队列末尾，当前歌曲结束后依次播放。用户队列优先于四种背景播放源：网易云歌单、心动 FM、QQ 歌单和 QQ 私人雷达。

默认每位用户最多保留 10 首待播歌曲，整个队列最多 300 首；管理员可在“控制设置”修改，点歌区显示的总上限同步更新。同一平台的同一首歌曲正在播放或已经排队时，不能重复添加。

### 删除、顶歌与跳过

| 操作 | 效果 |
| --- | --- |
| 删除 | 删除自己点的待播歌曲；正在播放的歌曲通过投票或管理员控制跳过 |
| 🔥顶 | 给待播歌曲顶一次；默认累计 3 次后升到队首，成为下一首 |
| 跳过投票 | 给当前歌曲投一票；默认达到 8 票后跳过 |

同一身份对同一首歌只能顶一次，对当前歌曲只能投一次跳过票。切歌后跳过票数重置。管理员可调整门槛。

预计播完时间依据歌曲时长、当前进度和队列计算；暂停、插播或音源失败会影响实际时间。

## 管理员操作

打开 `/admin.html`，输入管理口令进入控制台。

### 播放控制

- **开始播放**：播放器未运行时，启动待播歌曲或背景音乐。
- **暂停 / 继续**：暂停当前歌曲，或继续播放。
- **跳过**：结束当前歌曲，切换到下一首。
- **音量**：调整播放器音量，范围 0–100；电脑和音响自身也需有音量。
- **音频输出**：选择输出设备，或切回系统默认输出。
- **投票设置**：调整跳过所需票数和顶歌所需次数。

v1.0.16 默认对所有播放源启用响度均衡，目标为 -16 LUFS，真峰值上限为 -1.5 dBTP。该处理作用于音源，音量滑块仍控制最终音量；暂停、继续和切歌保留约 1 秒淡入淡出。实时均衡会减少歌曲间的响度差异，但不保证所有歌曲的听感完全一致。

### 控制设置（v1.0.17 起）

管理台新增“控制设置”，修改后点击 **保存控制设置**；**还原已保存**撤销尚未提交的编辑。其他状态刷新不会覆盖正在编辑的设置。

| 设置 | 默认值 | 生效方式 |
| --- | --- | --- |
| 每人点歌上限 | 10 首，可设 1–300 | 保存后立即生效；只计算待播歌曲，同 IP 的用户共享限额 |
| 点歌区总上限 | 300 首，可设 1–3000 | 保存后立即生效；所有用户共用，用户页面同步显示 |
| 启动自动播放 | 关闭 | 下次启动或重启主服务生效；开启后可能直接播放队列或背景音乐 |
| 响度均衡 | 开启 | 从下一首歌曲生效，不打断当前歌曲 |

设置会保存到本地配置，重启后保留。降低上限不会删除已排队歌曲；已有待播数量达到或超过新上限时，暂停接受超限点歌，直到数量下降。保存失败时原设置继续生效。

### 管理端点歌与队列管理

在“管理端点歌”中选择平台、搜索歌曲并加入队列。结果中的“定时”用于创建定时任务。

队列数量多时，在队列区域内滚动查看：

| 按钮 | 用途 |
| --- | --- |
| 置顶 | 移到待播队列第一位，当前歌曲结束后播放 |
| ↑ / ↓ | 上移或下移一位 |
| ▶播放 | 立即切换到选中歌曲，会打断当前歌曲 |
| 删除 | 删除任意待播歌曲 |
| 清空 | 清空待播队列 |

### 背景播放源与歌单

用户队列为空时，按所选播放源播放：

- **网易云歌单**：使用网易云歌单，随机播放一轮后重新打乱顺序。
- **心动 FM**：使用网易云账号的私人推荐，需要可用的网易云登录状态。
- **QQ 歌单**：默认使用 QQ 热歌榜，也可选择自选 QQ 歌单，随机循环播放。
- **QQ 私人雷达**：使用 QQ 个性电台推荐，需要可用的 QQ 音乐登录状态。

在歌单管理区域先选择网易云或 QQ 音乐，再输入歌单名称搜索后点击“添加”；也可粘贴对应平台的歌单分享链接（支持短链接）或输入歌单 ID。两平台的预设与已选歌单独立保存，点击预设会启用对应平台的歌单播放源；QQ 页可点击默认热歌榜恢复默认。播放源旁的标签会随当前平台显示“网易云”或“QQ音乐”；切换管理标签只切换歌单列表，点击歌单预设才会切换播放源。

QQ 歌单链接支持桌面版 `y.qq.com/n/ryqq_v2/playlist/…`、手机分享页 `i2.y.qq.com/n3/other/pages/details/playlist.html?id=…` 和 `c6.y.qq.com` 短链接。粘贴分享链接前，请先切换到“QQ音乐”歌单管理。

未配置歌单时默认使用热歌榜。程序启动仍保持暂停；点击开始播放后，用户队列为空时播放所选背景播放源。歌单加载失败时等待点歌。

### 用户、日志与渠道

- **用户名单**：查看昵称、访问 IP、活跃情况和待播点歌数。
- **系统日志**：查看点歌、改名、顶歌、播放、管理操作和错误；管理台显示的系统日志按 72 小时保留规则清理。
- **平台账号与渠道**：保存音乐 Cookie、刷新状态、开启或关闭对应平台。渠道关闭后，用户端该平台的搜索、点歌和榜单提示维护中。

## 音乐账号与 Cookie

Cookie 让音乐接口使用你的登录状态。仅能搜索或查看榜单，不代表登录有效，也不代表会员歌曲可以播放。

### 获取并保存

桌面版优先使用管理台中的 **登录网易云 / 登录QQ音乐**，在程序内的官方页面登录后自动验证并保存。下面的手动复制方法适用于浏览器/源码运行方式。

1. 在浏览器登录对应音乐网站：网易云 `music.163.com`，QQ 音乐 `y.qq.com`。
2. 按 `F12` 打开开发者工具，进入 **Network / 网络**。
3. 刷新页面，选择音乐网站的一条请求，在 **Request Headers / 请求标头** 中找到 `Cookie`。
4. 复制完整 Cookie 值，即 `字段名=值; 字段名=值`；不要复制 `Cookie:` 标题或整个请求头。
5. 在管理台“平台账号与渠道”中粘贴到对应输入框，点击保存并刷新状态。
6. 点一首歌实际试听，确认音源和账号权限正常。

网易云 Cookie 通常包含 `MUSIC_U`；QQ 音乐 Cookie 通常包含 `uin` 和音乐登录密钥。应复制登录后的音乐网站请求所使用的完整 Cookie。

### 保存位置与有效性

- 桌面版：网易云 Cookie 保存到 `%APPDATA%/JukeboxDesktop/server/config.local.js`，QQ 音乐 Cookie 保存到 `%APPDATA%/JukeboxDesktop/qq/cookie.json`。这些目录由程序创建。
- 源码版：网易云 Cookie 保存到 `server/config.local.js`，首次使用前需创建该文件；QQ 音乐 Cookie 保存到 `QQMusicApi/data/cookie.json`。
- v1.0.20 起，QQ 音乐状态会区分“已登录”“登录已过期”和“已保存，暂未验证”；网络不可达不会被误判为已退出登录。

QQ Cookie 使用原子写入和本地 `.bak` 备份，主文件损坏或丢失时可恢复备份。后台请求默认使用已保存账号；重新登录或续期后，音源缓存按凭据隔离，避免继续使用旧凭据对应的链接。

桌面版会保存验证成功的官方浏览器登录会话，启动及每 10 分钟检查一次，并在每 4 小时尝试刷新官方页面。后台自动续期仍在启动及每 4 小时执行；续期失败不会清空 Cookie。官方会话仍有效时可自动恢复同一账号的新凭据，恢复请求不会覆盖稍后手动登录的账号。

本机保存浏览器会话不能延长 QQ 服务端的凭据有效期；平台撤销全部会话或要求验证时，仍需在管理台重新登录。旧版已经丢失的浏览器会话也需要重新登录一次。Cookie 是账号凭据，分享日志或备份时不要公开其值。

## 定时播放

### 创建任务

1. 在“管理端点歌”中找到目标歌曲，点击“定时”。
2. 在“定时播放”区域选择“每天”或“每周”。
3. 设置播放时间；每周任务还需至少勾选一天。
4. 点击“添加定时任务”，确认任务出现在列表中且已启用。

任务支持启用、停用和删除。修改歌曲或时间时，删除旧任务后重新创建。

### 执行规则

- 使用服务电脑的本地时间和时区，按分钟匹配，约每 15 秒检查一次，并非精确到秒。
- 到点打断当前歌曲，优先播放定时歌曲；结束后从头恢复被打断的歌曲，不会恢复到原来的秒数。
- 同一时刻的多个任务按顺序播放。
- 没有歌曲正在播放时，启用的定时任务也会尝试播放。
- 服务必须运行；关机、休眠或服务停止期间错过的任务不会事后补播。
- 任务仍受渠道开关、网络、Cookie 和歌曲权限影响。正式使用前，建议设一个几分钟后的任务试听。

## 关闭重启与备份

### 关闭与重启

管理台“系统控制”提供重启和关闭功能，操作前保存状态。这里控制的是主服务，两个音乐 API 为独立进程。

桌面版可在首页 **启动主服务**，或选择 **重启全部服务**恢复全部服务；完全退出时使用 **退出软件**或托盘 **退出**。源码版关闭后再次双击 `start-silent.vbs` 启动。关闭浏览器不会停止后台服务，静默运行时也可以通过管理台控制。

默认 `autoStart: false` 时，重启后等待点击“开始播放”，此前未播完的歌曲放回队列首位。恢复播放从歌曲开头开始。

### 备份与迁移

桌面版先完全退出程序，再备份 `%APPDATA%/JukeboxDesktop` 整个用户数据目录；其中还包括桌面端口设置和平台登录会话。可以从首页的 **用户数据**按钮打开该目录。迁移到新电脑后，音乐账号可能需要重新登录。

源码版先关闭服务，再备份以下实际存在的文件：

| 文件 | 内容 |
| --- | --- |
| `server/config.local.js` | 管理口令、本地配置和网易云 Cookie |
| `QQMusicApi/data/cookie.json` | QQ 音乐 Cookie |
| `server/state.json` | 队列、当前歌曲、用户和播放源 |
| `server/presets.json` | 预设歌单 |
| `server/schedules.json` | 定时任务 |
| `server/channels.json` | 平台渠道开关 |

这些配置和运行数据被 Git 忽略。迁移时自行复制备份，并调整新电脑的 mpv 路径和音频设备；账号 Cookie 也可能需要重新登录获取。

## 常见问题

### 网页打不开

先在服务电脑打开 `http://127.0.0.1:8080`，端口修改过则换成实际端口。桌面版检查首页是否“服务运行中”，可点击 **重启全部服务**并查看“日志目录”。源码版本机也打不开时，检查 Node.js、依赖安装和日志：

```powershell
# 在项目根目录执行
Get-Content -LiteralPath './server/logs/main-server.log' -Encoding utf8 -Tail 50
Test-NetConnection 127.0.0.1 -Port 8080
```

网页资源缺失时，确认执行过 `npm --prefix ./web run build`。

本机可访问而其他设备不能访问时，检查服务电脑 IP、访客 Wi-Fi 隔离、网络互通及 Windows 防火墙的主服务访问规则。

### 服务端能打开，其他用户无法访问（防火墙）

服务电脑开启防火墙且没有放行点歌服务时，其他用户可能无法访问，即使本机能正常打开页面。推荐添加防火墙入站规则放行实际使用的 **TCP 主服务端口**（默认 `8080`），无需长期关闭防火墙。

1. 确认服务电脑和其他用户连接同一局域网，使用首页显示的服务电脑 IP 地址访问，不要在手机上使用 `127.0.0.1`。
2. 在 Windows 中打开 **Windows 安全中心 → 防火墙和网络保护 → 高级设置 → 入站规则 → 新建规则**。
3. 选择 **端口 → TCP → 特定本地端口**，填写实际服务端口，例如 `8080`；选择 **允许连接**。
4. 勾选当前可信局域网对应的网络配置文件（如“专用”或组织的“域”），给规则命名后保存。
5. 重新用其他设备访问。端口更改后，需要同步修改或重新建立此规则；手机访问无需放行内部 API 的 `3400` 和 `4000` 端口。

也可以在服务电脑以管理员身份打开 PowerShell，为**专用网络的本地子网**添加规则：

```powershell
# 8080 改为首页显示的实际主服务端口；此示例仅适用于专用网络
New-NetFirewallRule -DisplayName '局域网点歌机 TCP 8080' -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8080 -Profile Private -RemoteAddress LocalSubnet
```

命令参数说明见 [Microsoft 的 New-NetFirewallRule 文档](https://learn.microsoft.com/en-us/powershell/module/netsecurity/new-netfirewallrule)。如果当前是“公用”网络，上面的专用网络规则不会生效，应先核对当前网络类型；只把可信局域网设为专用网络。

也可在可信局域网中**短暂关闭当前网络的防火墙进行排查**；若关闭后恢复访问，重新开启防火墙并按上述方法放行。若安装了其他安全软件，还需检查其防火墙规则。放行后仍无法访问时，继续检查 IP 地址、访客网络隔离和服务状态。

### 管理端用户名全显示“匿名”

v1.0.18 修复了已保存昵称未同步到用户表的问题。升级后，点歌用户刷新页面即可补回浏览器中已保存的昵称；用户表已有明确昵称时，不会被旧浏览器缓存覆盖。没有点歌队列时修改昵称也会保存，重启后保留。

启动时会尝试从旧的待播歌曲记录补回缺失昵称。用户从未设置昵称、浏览器缓存和历史记录中都没有昵称时，仍显示“匿名”；可在点歌台顶部修改昵称。昵称来自用户填写，不是根据 IP 自动生成。

### 播放歌曲时弹出 mpv 封面窗口

部分音源包含封面图片，mpv 可能将图片作为视频显示。v1.0.18 强制只播放音频，禁用视频、封面窗口和播放器屏幕控件；管理台仍可控制暂停、继续、音量和输出设备。

### 能点歌但没有声音

1. 管理台点击“开始播放”，确认未暂停。
2. 检查 mpv 路径是否正确。
3. 检查管理台音量、Windows 音量、音响电源和输出设备。
4. 查看系统日志是否有音源获取失败，换一首可播放歌曲排除单曲权限问题。

音频由服务电脑输出，检查该电脑连接的音响。

### 每首歌的音量仍有差异

v1.0.16 起默认开启自动响度均衡；若使用旧版本，先升级。v1.0.17 可在管理台“控制设置”开启响度均衡，保存后从下一首生效。手动修改本地配置 `loudnessNormalization` 则需重启主服务。音量滑块、Windows 音量和音响音量控制整体输出，不会单独统一每首歌的录音响度。

在线歌曲使用实时均衡，安静前奏、强弱变化和不同录音的听感仍可能不同。淡入淡出处理播放过渡，与响度均衡分别起作用。

### QQ 音乐或网易云无法连接

确认渠道开启，并检查对应 API：

```powershell
Test-NetConnection 127.0.0.1 -Port 3400
Test-NetConnection 127.0.0.1 -Port 4000
Get-Content -LiteralPath './server/logs/qqmusic-api.log' -Encoding utf8 -Tail 50
Get-Content -LiteralPath './server/logs/netease-api.log' -Encoding utf8 -Tail 50
```

端口成功只表示本地 API 可连接，并不证明音乐平台登录或音源正常。桌面版内部 API 端口可能因占用而自动改变，应使用首页显示的实际端口；需要重启两个音乐 API 时，使用首页的 **重启全部服务**，管理台的“重启服务”只重启主服务。搜索正常但播放失败时，重新登录或保存有效 Cookie、换歌曲测试，并查看系统日志中的原因。

### Cookie 已保存，歌曲仍被跳过

可能是 Cookie 失效、会员或版权限制、网络异常，或平台未返回可用音源。不可播放歌曲会记录错误并尝试下一首。

先用少量不同歌曲测试，根据日志区分单曲不可用和整个渠道异常。QQ 音乐“已配置”不是有效登录保证。

### 歌曲播放失败，提示 HTTP 502 并自动跳过

表示获取音源的 API 请求失败，可能与上游接口或网络有关，不能仅凭这一条日志判断 Cookie 已失效。v1.0.16 当前会直接跳过失败歌曲，不会自动重试该次请求。稍后重新点入同一首歌，并用其他歌曲判断是偶发故障还是整个平台异常；持续失败时检查网络、登录状态及系统日志。

### 点歌归属或限额异常

检查是否从不同网络访问，或多人共用代理 IP。相同 IP 的身份会合并；管理员可在用户名单和队列中核对。

### 静默运行如何查看日志

桌面版可从首页 **日志目录**查看 `%APPDATA%/JukeboxDesktop/logs/desktop.log` 中的服务状态；管理台查看播放、点歌和错误日志，对应用户数据目录内的 `server/logs/system.log`。源码版启动脚本的输出在 `server/logs/main-server.log`、`qqmusic-api.log`、`netease-api.log`。分享前遮盖账号凭据和个人信息。

## 配置项参考

在 `server/config.local.js` 设置以覆盖默认值。下表为程序默认值，不代表当前电脑的实际配置。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `port` | `8080` | 主服务端口 |
| `neteaseApiBase` | `http://127.0.0.1:4000` | 网易云 API 地址 |
| `qqApiBase` | `http://127.0.0.1:3400` | QQ API 地址，可加入本地配置 |
| `adminKey` | 空字符串 | 管理口令，空值禁用管理功能 |
| `neteaseCookie` | 空字符串 | 网易云 Cookie |
| `mpvPath` | `mpv` | 播放器路径或 PATH 中的命令名 |
| `volume` | `100` | 初始音量，0–100 |
| `loudnessNormalization` | `true` | 双平台自动响度均衡，`false` 可关闭；重启主服务生效 |
| `audioDevice` | 空字符串 | 初始输出设备，空值使用系统默认 |
| `playlistId` | `3778678` | 默认网易云热歌榜，未配置或 0 时使用此榜 |
| `qqPlaylistId` | `0` | QQ 自选歌单，0 表示使用默认 QQ 热歌榜 |
| `qqChartId` | `26` | 默认 QQ 热歌榜的榜单 ID |
| `presetPlaylists` | 热歌榜 | 管理台预设歌单 |
| `fmMode` | `false` | 初始使用心动 FM 与否，保存的运行状态可能覆盖此值 |
| `autoStart` | `false` | 启动后是否立即播放 |
| `maxPerUser` | `10` | 每人待播上限 |
| `maxUserQueue` | `300` | 待播队列上限 |
| `skipRequired` | `8` | 初始跳过投票门槛 |
| `boostRequired` | `3` | 初始顶歌门槛 |
| `searchCacheMs` | `30000` | 搜索缓存时间，毫秒 |

本项目依赖第三方音乐服务接口。使用歌曲时请遵守相应平台的服务条款及歌曲授权要求。
